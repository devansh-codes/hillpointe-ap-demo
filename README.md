# Hillpointe AP: read-only demo

Static, read-only build of the web app from the Hillpointe accounts-payable automation exercise. It shows the submitted
runs (Invoice Batch 01, its rerun, and Batch 02): the Intacct import, Entrata handoff, exception log, approvals, and for every
document the reason for its decision next to the source PDF.

Processing new invoices, imports and rule changes run in the local application; this site cannot change anything.
All vendors, invoices, amounts and bank details are fictional exercise data.
